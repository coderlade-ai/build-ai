# ADR 0012: Portuguese locale variant

- **Status:** Accepted (owner confirmed 2026-10-25)
- **Date:** 2026-10-25

## Context

The `pt` locale variant is unspecified.

## Decision

**pt-BR** (Brazilian Portuguese), confirmed by the owner on 2026-10-25. The route prefix stays `/pt`; `lang` and `hreflang` use `pt-BR`.

## Consequences

Owner decision required.
